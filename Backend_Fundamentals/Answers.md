# Backend Fundamentals

## (a) What is backend development and what role does it play in a web or mobile application?

Backend development is the part of an application that runs on the server and handles the application's logic, data, authentication, and communication with the database. It receives requests from the frontend, processes them, and sends back the required response.

## (b) What is an API? Give one practical example.

An API (Application Programming Interface) allows different software systems to communicate with each other.

For example, a weather application can use a weather API to send a request for the weather of a city and receive the current weather data in response.

## (c) What is a REST API, and what are GET, POST, PUT/PATCH, and DELETE used for?

A REST API is an API that follows REST principles and uses HTTP methods to work with resources.

* GET: Retrieve data.
* POST: Create new data.
* PUT/PATCH: Update existing data.
* DELETE: Delete data.

## (d) Explain the difference between authentication and authorization.

Authentication verifies who a user is, while authorization determines what that authenticated user is allowed to access or do.

For example, logging in with an email and password is authentication. Being allowed to access an admin dashboard after logging in is authorization.

## (e) What is JSON and why is it commonly used for API communication?

JSON is a lightweight text-based format used to represent and exchange data. It is commonly used for API communication.
